# Pretty Wise Tips — Attention Is Not Consistency

## Download the animated video

Open [the MP4](exports/pretty-wise-tips-animated-v2.mp4), then choose **Download raw file** on GitHub.

The video is a 47-second, 1080 × 1920, 30 fps H.264 animated silent timing preview. ElevenLabs narration has not been supplied.

## Editable source

The [Remotion project](pretty-wise-tips/) includes the SVG character, scene components, brand colors, exact narration script, editable provisional timing map, lockfile, and render instructions. See its [README](pretty-wise-tips/README.md).

To download the editable project as a ZIP, use the repository's **Code → Download ZIP**, or use [the source archive](exports/pretty-wise-tips-editable-source.zip).

The exported MP4 is the revised animation with floating cards, drawn highlights and connectors, calendar entries, character motion, and sliding notifications. Dependencies are excluded; install them with `npm ci`.
